## 1. Introduction to Artificial Intelligence

Artificial Intelligence (AI) is a branch of computer science that focuses on developing machines and computer systems capable of performing tasks that typically require human intelligence.

These tasks include problem-solving, decision-making, learning, language understanding, image recognition and pattern identification.

### Applications of AI
- Virtual assistants and chatbots.
- Facial recognition systems.
- Autonomous vehicles.
- Medical diagnosis support.
- Recommendation systems.
- Fraud detection.

## 2. Machine Learning

Machine Learning (ML) is a subset of Artificial Intelligence that enables computers to learn from data and improve their performance without being explicitly programmed for every individual task.

Machine Learning algorithms identify patterns in datasets and use those patterns to make predictions or decisions.

### Types of Machine Learning

**1. Supervised Learning**

The model learns using labelled datasets containing input data and their corresponding correct outputs.

Examples:
- Email spam classification.
- House price prediction.
- Student performance prediction.

**2. Unsupervised Learning**

The model identifies hidden patterns and relationships in data without predefined labels.

Examples:
- Customer segmentation.
- Grouping similar documents.
- Anomaly detection.

**3. Reinforcement Learning**

The model learns by interacting with an environment and receiving rewards or penalties based on its actions.

Examples:
- Game-playing systems.
- Robotic navigation.
- Autonomous decision-making.

## 3. Deep Learning

Deep Learning (DL) is a specialized subset of Machine Learning that uses artificial neural networks containing multiple layers to learn complex patterns from large datasets.

These networks are inspired by the structure and functioning of biological neural networks.

### Applications of Deep Learning
- Speech recognition.
- Facial recognition.
- Medical image analysis.
- Natural language processing.
- Autonomous driving.
- Generative AI.

## 4. Difference Between AI, ML and DL

| Feature | Artificial Intelligence | Machine Learning | Deep Learning |
|---|---|---|---|
| Definition | Machines performing intelligent tasks | Machines learning from data | Learning using multilayer neural networks |
| Scope | Broadest concept | Subset of AI | Subset of ML |
| Approach | Reasoning and intelligent behaviour | Statistical learning | Neural network-based learning |
| Data requirement | Depends on application | Requires training data | Often requires large datasets |
| Example | Chess-playing system | Spam detection | Facial recognition |

**Relationship:**

Deep Learning is a subset of Machine Learning, and Machine Learning is a subset of Artificial Intelligence.

## 6. Important AI Technologies

**Natural Language Processing (NLP):** Enables computers to understand, interpret and generate human language.

**Computer Vision:** Enables computers to analyze and understand images and videos.

**Generative AI:** Uses trained models to generate new content, including text, images, audio and code.

**Robotics:** Combines intelligent software with physical machines to perform automated tasks.

## 7. Basic Understanding of Neural Networks

An artificial neural network is a computational model inspired by biological neurons.

A typical neural network consists of:

1. Input Layer – Receives input data.
2. Hidden Layers – Process information and identify patterns.
3. Output Layer – Produces the final prediction or result.

Deep Learning systems use multiple hidden layers to learn complex representations from data.
